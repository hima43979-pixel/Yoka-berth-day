موقع عيد ميلاد YOKA ❤️

لتشغيل الموقع:
1) فك ضغط الملف.
2) افتح index.html للتجربة، أو ارفع كل محتويات المجلد إلى مستودع GitHub.
3) على GitHub افتح Settings > Pages.
4) من Build and deployment اختار Deploy from a branch، ثم branch main والمجلد /(root)، واضغط Save.
5) بعد دقائق سيظهر رابط الموقع في صفحة Pages.

مهم: لازم ترفع مجلد assets كما هو مع index.html عشان الصور والأغنية تشتغل.
الأغنية لا تبدأ تلقائياً في أغلب المتصفحات؛ اضغط تشغيل بنفسك.
